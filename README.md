# Bécalos Tech Challenge - Módulo 6: Desarrollo con React

Este repositorio está dedicado a recopilar todos los ejercicios y proyectos desarrollados durante el **Módulo 6** del programa **Bécalos Tech Challenge**. El enfoque principal de esta etapa es el aprendizaje de **React**, comprendiendo desde la creación de componentes funcionales y el manejo del estado, hasta el uso de hooks, composición de componentes, enrutamiento y el desarrollo de una aplicación completa.

## 📂 Organización del Repositorio

Para facilitar la navegación y el aprendizaje, el repositorio se organiza bajo la siguiente estructura:

- **Carpetas:** Cada tema o proyecto cuenta con su propio directorio independiente.
- **Archivos:** Dentro de cada carpeta se encuentran los archivos correspondientes de cada solución (`.jsx`, `.js`, `.css`, `.html` cuando aplique).
- **Documentación Local:** Cada ejercicio incluye su propio archivo `README.md` detallando los objetivos, conceptos aprendidos y la implementación realizada.

## 📋 Lista de Proyectos y Ejercicios

A continuación se detallan los temas y proyectos desarrollados durante el módulo de React:

### React
| Proyecto / Tema | Descripción | Estado |
| :--- | :--- | :---: |
| **01. Intro a React** | Introducción a React y creación de componentes funcionales. | Hecho |
| **02. Manejo de Estado** | Uso de Props y del hook `useState` para gestionar el estado de los componentes. | Hecho |
| **03. Hooks: useEffect y useMemo** | Manejo de efectos secundarios, ciclo de renderizado y optimización mediante memoización. | Hecho |
| **04. Ciclo de Vida de Componentes** | Comprensión del ciclo de vida en componentes funcionales y comparación con hooks clásicos. | Hecho |
| **05. Conditional Rendering y Components Composition** | Renderizado condicional y reutilización de componentes mediante composición. | Hecho |
| **06. Hooks Avanzados** | Implementación de `useRef`, `useCallback` y `useReducer` para escenarios más complejos. | Hecho |
| **07. Manejo de Rutas** | Navegación entre vistas utilizando `react-router-dom`. | Hecho |
| **08. Proyecto Final** | Desarrollo de una aplicación integrando los conceptos vistos durante el módulo. | Hecho |
